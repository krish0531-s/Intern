# Internship Projects

This repository contains projects developed during my internship and independent engineering work. The focus is on building practical software systems that automate business workflows and process large volumes of documents efficiently.

## Projects

### Document Automation System

A configurable document management and automation tool that streamlines client onboarding and compliance document handling.

Features:

* Automatic client folder structure generation
* Configurable document templates using `checklist.txt`
* Support for deeply nested folder hierarchies
* Excel-based document mapping with dropdown selection
* Human-in-the-loop document verification
* Automatic document renaming and routing
* Optional custom naming convention
* Standalone Windows executable deployment

**Technologies:** Python, OpenPyXL, Tkinter, PyInstaller

---

### PDF Analyser

An AI-powered document processing platform for extracting structured information from PDF documents.

Features:

* PDF upload and storage pipeline
* Text extraction workflow
* Processing state management
* Database-backed document tracking
* AI-ready extraction architecture
* FastAPI-based backend design

**Technologies:** Python, FastAPI, SQLAlchemy, Alembic, SQLite
